# [Mini Bank Manager] 간단 은행 계좌 관리 프로그램

### 주제
- 자바 객체지향을 사용한 은행 계좌 관리 프로그램

### 개발 스펙
1. 계좌 개설
2. 고객 계좌 조회
3. 입금
4. 결제
5. 계좌이체
6. 거래내역 조회
7. 전체 계좌 조회

### 개발 일정
- 5/11 ~ 5/13 전체 구조 확정
요구사항 분석 및 클래스 구조 설계
- 5/14 ~ 5/18 핵심 클래스 구현
BankAccount, Transaction 완성
- 5/19 ~ 5/23 핵심 기능 동작
입금/결제/이체 기능 구현
- 5/24 ~ 5/27 계좌 관리 기능
BankService 통합 관리 기능 구현
- 5/28 ~ 5/31 프로토타입 완성
GUI 연결 및 프로토타입 제작
- 6/1 수정사항 정리
프로토타입 제출 및 피드백
- 6/2 ~ 6/7 안정성 향상
기능 보완 및 예외처리 강화
- 6/8 ~ 6/10 최종 버전 준비
통합 테스트 및 오류 수정
- 6/11 최종 제출 준비
제출물 점검
- 6/12 프로젝트 완료
최종 제출

### 개발 계획
1. 설계 단계
- 클래스 구조 및 역할 분담 확정
- 계좌 정보와 거래내역 구조 설계
2. 기능 구현 단계
- 계좌 생성 및 조회 기능 구현
- 입금, 결제, 계좌이체 기능 구현
- 거래내역 저장 기능 구현
- 예외처리 추가
- 음수 금액 입력 방지
- 비밀번호 확인
- 마이너스 한도 검사
- 중복 계좌 생성 방지
3. GUI 연동 단계
- GUI 화면 구성
- 버튼 및 입력 기능 연결
- 사용자 화면 테스트
4. 테스트 및 마무리 단계
- 기능별 오류 테스트
- GUI 동작 점검
- 코드 정리
